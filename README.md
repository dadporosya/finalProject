
# Мафия-бот

> Телеграм-бот для игры в мафию по сети прямо в мессенджере!

---

Установка:
Клонируйте репозиторий в терминале вашего IDE:
```bash
git clone https://github.com/dadporosya/finalProject.git
```

## Запуск

1. Откройте файл `project/config.py` и укажите токен вашего Telegram-бота в переменной `TOKEN`.
2. Запустите `project/main.py`.
3. Бот успешно запущен!

---

## Пользование

После запуска используйте команду `/start`, чтобы начать взаимодействие.  
Бот отправит список доступных команд с описанием и запустит процесс регистрации.

> Перед использованием бота необходимо зарегистрироваться с помощью команды `/start` или `/register`.

---

## Лобби

### Создание лобби — `/create`

1. Введите команду `/create`.
2. Введите название лобби (оно понадобится другим игрокам для входа).
3. Выберите игру *(пока доступна только Мафия)*.
4. Лобби успешно создано!

### Вход в лобби — `/join`

1. Введите команду `/join`.
2. Введите название лобби, к которому хотите присоединиться.
   - Если лобби существует — бот подтвердит вход. Хост получит уведомление.
   - Если лобби не найдено — бот сообщит об ошибке.

---

## Начало игры — `/startGame`

Если у вас есть созданное лобби, то после команды, начнётся игра! Команда доступна только хосту лобби.

---

## Игровой процесс

Игра проходит по **классическим правилам мафии**.

### Роли

| Роль | Цель |
|------|------|
| Мафия | Убить достаточно мирных жителей, чтобы численно сравняться с ними |
| Мирный житель | Вычислить и казнить всех мафиози |

В начале игры каждый игрок узнаёт свою роль. Игроки мафии также узнают имена друг друга.

---

### 🌙 Ночь

Игроки мафии голосуют за жертву. Игрок, набравший наибольшее число голосов будет убит.

### ☀️ День

Каждый игрок по очереди высказывается и пишет боту своё мнение о текущей ситуации.  
После отправки сообщения его речь увидят все участники, и ход переходит к следующему.

### Голосование

После того как все высказались, начинается общее голосование.  
Игрок, набравший наибольшее число голосов будет казнён.

Раунды продолжаются до тех пор, пока одна из сторон не выполнит своё условие победы.

> После окончания игры хост может запустить её снова командой `/startGame`.

---

## Список команд

| Команда | Описание | Доступ            |
|---------|----------|-------------------|
| `/info` | Список всех команд | Все               |
| `/register` | Регистрация или смена имени | Все               |
| `/create` | Создать лобби | Все               |
| `/join` | Войти в лобби | Все               |
| `/deleteLobby` | Удалить текущее лобби | Только хост лобби |
| `/startGame` | Запустить игру | Только хост лобби |
| `/endGame` | Досрочно завершить игру | Только хост лобби |
